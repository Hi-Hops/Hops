# hops-system-1 가상 시연 seed

`hops_system_1_demo.sql`은 원격 `develop`의 개발용 회원·시스템 seed를 이용하는 **수동 실행 전용** 가상 데이터다. 실제 인물이나 업무 기록이 아니다. Flyway 자동 실행 경로에는 넣지 않는다.

전용 개발 DB에 Flyway 스키마와 `db/seed`의 개발용 회원·시스템을 적용하거나, 기존 AWS 시연 계정·시스템을 준비한다. 이후 이 파일을 `psql -X -v ON_ERROR_STOP=1`로 명시 실행한다. 필요한 개발용 또는 기존 시연 계정이나 시스템이 없거나 시연 문의·메시지의 ID 또는 문의 번호가 이미 있으면 전체 거래를 중단한다. 기존 행을 삭제·수정하거나 덮어쓰지 않는다. 재실행도 중단된다. 실제 운영 DB에 실행하지 않는다.

개발용 `requester1` 계정에 문의 4건, `requester3` 계정에 문의 1건을 추가한다. 기존 AWS 시연 계정만 있다면 각각 `demo.requester`, `demo.file`을 사용한다. 각 문의의 상세와 대화 조회, 계정별 문의 분리와 시스템 목록을 확인할 수 있다. 계정과 비밀번호는 이 파일에서 생성하거나 바꾸지 않으며 [Spring 실행 안내](../../../../../README.md)의 개발용 seed를 따른다.

현재 원격 문의 상세 API에서 조회할 수 있도록 문제·AI 실행이 없는 문의자 메시지만 넣는다. 티켓·AI 답변·처리·해결·사례·검색 색인은 만들지 않는다. 따라서 이 seed의 적용 성공은 해당 기능이나 프론트–백엔드 E2E 검증을 뜻하지 않는다. 이전 버전의 시연 문의가 이미 있다면 이 파일은 충돌을 감지하고 중단한다. 기존 데이터를 자동으로 교체하지 않는다.
