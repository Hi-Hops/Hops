# SMB 파일 서버 Event ID 1020 지연 진단 및 대응

## 적용 범위와 사용자 증상

- 서비스/컴포넌트: FILE_SHARE / SMB
- 기본 담당: SYSTEM
- 적용 환경: HOPS_VIRTUAL_COMPANY
- 제품: Windows Server SMB 지원 버전, Windows 11
- 문서 상태/인덱싱: DRAFT / PENDING

## 적용 가정

- 가상 기업 공유 드라이브는 Windows Server 기반 SMB 파일 서버를 사용한다.
- SMBServer Operational 이벤트와 디스크 지연 집계는 권한이 적용된 읽기 전용 경로로 조회한다.
- Event ID 1020은 파일 시스템 I/O 지연 신호이며 특정 저장장치 원인을 단독 확정하지 않는다.
- Agent는 필터 드라이버 제거, 백업 중지, 저장장치 설정 변경, 서버 재시작을 수행하지 않는다.

## 범위 밖

- SMB Access Denied 또는 인증 정책 오류
- DNS·TCP 445·방화벽으로 경로를 찾지 못하는 장애
- Agent가 trace·dump 수집 설정을 변경하거나 저장장치 복구를 수행하는 작업

## 사용자 증상

### SYM-01

사용자 표현:
- 공유 파일을 열거나 저장하는 데 너무 오래 걸려요.
- Z 드라이브가 멈춘 것처럼 보여요.

관측 신호:
- SMBServer Operational 로그에 Event ID 1020이 기록된다.
- 이벤트에 15초 이상 지연된 파일 시스템 작업과 SMB command가 기록된다.

### SYM-02

사용자 표현:
- 여러 사람이 같은 공유 폴더에서 느려요.
- 파일 서버의 다른 프로그램도 함께 멈추는 것 같아요.

관측 신호:
- 여러 SMB 클라이언트와 서버 로컬 작업에서 I/O 지연이 같은 시간대에 발생한다.
- 특정 디스크 또는 저장 경로에 지연이 집중될 수 있다.

## 진단 1: 요청·로그 연결

### DIA-01 · 사용자 지연과 SMBServer Event ID 1020을 연결한다.

- 조치: 발생 시각과 마스킹된 공유·파일 범위를 확인하고 같은 시간대 Event ID 1020의 Duration, Warning Threshold, Command를 읽는다. 사용자명·IP·전체 파일명은 Agent 응답에서 마스킹한다.
- 도구: 미등록 — 실행 불가
- 기대 신호:
- 사용자 지연 시각에 Event ID 1020이 발생한다.
- 파일 시스템 작업 지연 시간이 경고 임계값을 넘는다.
- 일치 시: DIA-02에서 영향 범위와 반복 패턴을 확인한다.
- 불일치 시: Event ID 1020이 없으면 네트워크·권한·클라이언트 지연을 조사한다.
- 근거: GE-021

### DIA-02 · 특정 파일·디스크와 서버 전체 지연을 구분한다.

- 조치: Event ID 1020의 공유·command·duration을 집계하고 같은 시간대 논리 디스크 지연과 다른 서버 작업의 영향을 비교한다.
- 도구: 미등록 — 실행 불가
- 기대 신호:
- 특정 저장 경로 또는 여러 디스크·공유의 반복 패턴이 확인된다.
- SMB 외 서버 작업에도 I/O 지연이 있는지 구분된다.
- 일치 시: DIA-03에서 OS 내부와 외부 저장 계층 후보를 구분한다.
- 불일치 시: 반복 패턴이 없으면 단발 이벤트로 기록하고 원인을 확정하지 않는다.
- 근거: GE-021

## 진단 2: 계층 구분과 근거 충분성

### DIA-03 · 파일 시스템 필터와 물리·가상 저장 계층 원인 후보를 구분한다.

- 조치: 사람 담당자가 수집한 승인된 Storport·Perfmon·WPR 요약에서 하위 저장 계층 응답시간과 파일 서버 수준 지연을 비교한다. 원시 dump와 파일 경로는 Agent에 전달하지 않는다.
- 도구: 미등록 — 실행 불가
- 기대 신호:
- 하위 Storport 지연이 높거나 OS 상위 계층에서만 지연되는 패턴이 구분된다.
- 백업·필터 드라이버·하이퍼바이저·SAN/NAS 중 추가 확인 대상이 정리된다.
- 일치 시: CAUSE-01 또는 CAUSE-02 후보와 협업 부서를 기록한다.
- 불일치 시: 추적 데이터가 없으면 저장장치 원인을 단정하지 않고 SYSTEM으로 이관한다.
- 근거: GE-021

## 원인 후보와 반대 신호

### CAUSE-01 · 파일 시스템 필터 드라이버, VSS 또는 백업 작업이 파일 서버 I/O를 장시간 지연시킨다.

- 필요 신호 ID: SIG-050, SIG-051
- 필요 신호:
- Event ID 1020 반복
- 하위 저장장치 지연보다 파일 서버 상위 계층 지연이 크거나 백업·필터 작업 시간과 일치
- 반대 신호 ID: SIG-052
- 반대 신호:
- Storport 수준에서 동일한 높은 지연이 확인됨
- Event ID 1020이 사용자 증상 시간과 일치하지 않음
- 담당 부서: SYSTEM
- 근거: GE-021

#### 레지스트리에서 결합된 신호 정의

- SIG-050 [필요] · SMBServer Event ID 1020 (WINDOWS_EVENT)
  - 매칭: SMBServer/1020
  - 의미: 파일 시스템 작업이 경고 임계값보다 오래 걸린 I/O 지연 신호
  - 확정 제한: 파일 시스템 필터와 하위 저장 계층을 추가 구분
- SIG-051 [필요] · 파일 서버 상위 계층 작업 상관 (LAYER_CORRELATION)
  - 매칭: filesystem_filter_or_backup_correlation
  - 의미: Event ID 1020 발생 시각이 백업·바이러스 검사·파일 시스템 필터 작업과 일치하고 하위 저장 계층은 정상인 상태
  - 확정 제한: 작업 시각과 하위 저장 계층 지연을 함께 비교하기 전 상위 계층 원인으로 확정하지 않음
- SIG-052 [반대] · 하위 저장 계층 지연 (STORAGE_LATENCY)
  - 매칭: storport_or_storage_latency_high
  - 의미: Storport 또는 하위 저장 계층의 높은 응답시간이 SMB 지연과 같은 시각에 관측됨
  - 확정 제한: 단일 최대값이 아니라 사용자 증상·Event ID 1020과 시간 상관을 확인

## Agent 사용자 안내와 처리 경계

### GUID-01 · Agent 안내

- 조건: 공유 파일 지연이 발생하지만 서버 원인이 아직 확정되지 않은 경우
- 안내: 사용자에게 반복 저장을 중단하고 발생 시각·공유 드라이브·작업 종류만 기록하도록 안내한다. 파일 내용이나 민감한 전체 경로는 받지 않는다.
- 예상 결과: 중복 저장이나 파일 충돌 위험을 줄이고 이벤트와 연결할 최소 정보를 확보한다.
- 미해결 시: 같은 증상이 지속되면 SYSTEM으로 이관한다.
- 근거: GE-021

### GUID-02 · Agent 안내

- 조건: Event ID 1020 또는 여러 사용자 영향이 확인된 경우
- 안내: 사용자에게 파일 서버 저장 처리 지연이 확인되어 담당 부서가 점검 중이라고 안내한다. 서버·저장장치·사용자 세부정보는 노출하지 않는다.
- 예상 결과: 사용자가 공통 장애임을 이해하고 불필요한 재시도를 멈춘다.
- 미해결 시: 담당자 재시험과 사용자 해결 확인 전까지 티켓을 유지한다.
- 근거: GE-021

### Agent 처리 경계

- 허용 결과: GUIDE_USER, HANDOFF
- 이관 사유: INSUFFICIENT_EVIDENCE, GUIDANCE_NOT_RESOLVED
- 금지 작업: CODE_CHANGE, CONFIG_CHANGE, DEPLOY, RESTART, DB_WRITE
- 해결 확정 근거: USER_CONFIRMATION, BACKEND_STATE

## 이관 후 IT 담당자 조치·검증

### RES-01 · 사람 수행

- 조치: Event ID 1020의 시간·duration·command·마스킹된 저장 경로를 집계하고 같은 시간대 백업·필터·디스크 작업을 대조한다.
- 승인 필요: 아니오
- 확인: 재현 또는 반복 이벤트와 영향 저장 계층이 시간상 연결된다.
- 롤백: 해당 없음
- 근거: GE-021

### RES-02 · 사람 수행

- 조치: 필요하면 승인된 유지보수 창에서 Storport·Perfmon·WPR 추적을 수집해 OS 내부와 외부 저장 계층을 구분한다. 라이브 kernel dump는 별도 보안 절차로만 취급한다.
- 승인 필요: 예
- 확인: 상위·하위 계층 지연 차이를 설명할 수 있는 추적 결과가 확보된다.
- 롤백: 추적이 성능에 영향을 주면 즉시 수집을 중단하고 생성 파일을 보안 위치로 이동한다.
- 근거: GE-021

### RES-03 · 사람 수행

- 조치: 확정 원인에 따라 필터·백업 일정은 SYSTEM이, 하이퍼바이저·디스크·SAN/NAS는 INFRA가 승인된 변경으로 조치한다.
- 승인 필요: 예
- 확인: 같은 업무 부하에서 Event ID 1020과 사용자 지연이 재발하지 않는다.
- 롤백: 새 I/O 오류 또는 서비스 장애가 발생하면 변경을 되돌리고 티켓을 재개한다.
- 근거: GE-021

### 완료 판정

성공 신호:
- 같은 부하에서 Event ID 1020이 재발하지 않는다.
- 파일 열기·저장 시간이 정상 범위로 회복된다.
- 사용자와 서버 상태가 해결을 확인한다.

실패 신호:
- Event ID 1020이 계속 발생한다.
- 저장 계층 지연이 유지된다.
- 사용자가 계속 긴 파일 작업 지연을 경험한다.
