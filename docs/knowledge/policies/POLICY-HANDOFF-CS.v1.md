# 티켓 생성·부서 이관·재이관·CS 검토 규칙

## 목적

Agent의 티켓·부서 제안과 Spring의 업무 확정을 분리하고 재이관·부분 실패·CS 검토를 안전하게 처리한다.

## 규칙

### 10 · RULE-HANDOFF-CREATE

- 조건: 직원 안내로 해결되지 않고 담당 부서의 처리가 필요함
- Agent 동작: 문제 요약·근거·확인 결과·후보 부서가 포함된 티켓 초안을 제안한다.
- 최종 권한: SPRING
- 강제 지점: Spring은 요청 권한·근거·부서·멱등 키를 검증하고 티켓과 최초 배정을 함께 확정한다.
- 필수 근거:
- 문의 문제 식별자
- 진단 근거 또는 근거 부족 사실
- 후보 부서 이유
- 사용자에게 보이는 동작: 확정 저장된 티켓 번호와 처리 부서만 결과 카드로 보여 준다.
- 금지 결과:
- Agent의 직접 티켓 저장
- 저장 ACK 전 생성 완료 표시
- 확인 근거 없는 부서 확정

### 20 · RULE-HANDOFF-PARTIAL

- 조건: 복합 문의의 일부 티켓만 생성·배정에 성공함
- Agent 동작: 성공·추가 질문·실패 항목을 문제별로 구분해 반환한다.
- 최종 권한: SPRING
- 강제 지점: Spring은 성공 티켓을 유지하고 실패 작업을 같은 작업 ID로 재시도 가능하게 보존한다.
- 필수 근거:
- 문제별 작업 ID
- 저장 결과와 오류 코드
- 사용자에게 보이는 동작: 성공한 티켓과 아직 처리 중이거나 실패한 문제를 구분한다.
- 금지 결과:
- 전체 성공으로 표시
- 성공 티켓 롤백
- 재시도 중복 티켓 생성

### 30 · RULE-HANDOFF-REASSIGN

- 조건: 현재 처리 부서가 근거와 함께 재이관을 요청함
- Agent 동작: 재이관 사유와 이미 제외된 부서를 반영해 남은 후보 부서를 다시 제안한다.
- 최종 권한: SPRING
- 강제 지점: Spring은 현재 배정·제외 이력·권한을 검증하고 새 배정과 이력을 원자적으로 저장한다.
- 필수 근거:
- 재이관 사유
- 현재·이전 부서
- 제외 부서 목록
- 새 후보 근거
- 사용자에게 보이는 동작: 재이관이 확정된 뒤 변경된 처리 부서를 표시한다.
- 금지 결과:
- 제외 부서로 순환 배정
- 기술 실패를 재이관 성공으로 표시
- Agent의 직접 배정 변경

### 40 · RULE-HANDOFF-EXHAUSTED

- 조건: 유효한 처리 부서 후보가 모두 소진됨
- Agent 동작: 임의 부서를 만들지 않고 배정 예외와 확인된 근거를 반환한다.
- 최종 권한: HUMAN
- 강제 지점: 업무 관리자가 수동 배정 또는 재검토 결과를 기록한다.
- 필수 근거:
- 검토한 후보와 제외 이유
- 남은 불확실성
- 사용자에게 보이는 동작: 관리자 검토가 필요함을 안내한다.
- 금지 결과:
- 임의 순환 배정
- CS로 무조건 전환
- 티켓 삭제

### 50 · RULE-HANDOFF-CS

- 조건: 추가 질문 한도 후에도 분류되지 않는 IT 문의이거나 정상적인 CS 검토가 필요한 문의
- Agent 동작: 기술 실패와 구분해 CS 검토 사유를 제안한다.
- 최종 권한: SPRING
- 강제 지점: Spring은 질문 횟수·범위 판단·실행 오류를 검증해 CS 검토 여부를 확정한다.
- 필수 근거:
- 질문 횟수
- 분류 실패 이유
- 모델·통신 오류와의 구분
- 사용자에게 보이는 동작: 추가 검토가 필요한 이유를 설명한다.
- 금지 결과:
- 모델 시간 초과를 CS 문의로 저장
- 범위 밖 질문의 기술 티켓 생성
- CS를 배정 실패 복구 수단으로 사용

## 공통 금지 사항

- Agent의 업무 DB 직접 쓰기
- 사용자 승인 단계를 티켓 생성 조건으로 추가
- 재이관·복구·CS 상태 혼합
- 성공 티켓과 실패 작업의 식별자 재사용 오류

## 연결 대상

- 직원 가이드: GUIDE-COMMON-PROCESS, GUIDE-COMMON-SCOPE
- IT 런북: 없음
- 평가 시나리오: FLOW-GUIDANCE-NOT-SOLVED, FLOW-NO-EVIDENCE-HANDOFF, FLOW-REHANDOFF, FLOW-MULTI-PROBLEM, FLOW-CS-AFTER-THREE
