# 비밀번호 재설정 중 오류가 날 때

## 적용 상황

- 공식 셀프서비스 비밀번호 재설정 중 요청 처리 오류가 표시됨
- 등록 연락처로 본인 확인을 완료할 수 없음

## 사용자 표현

- 비밀번호 재설정 요청을 처리할 수 없다고 나와요.
- 재설정 인증 연락이 오지 않아요.

## 안전한 확인 순서

1. 오류 화면에서 다른 승인된 인증 방법을 선택할 수 있는지 확인합니다.
   - 예상 결과: 사용 가능한 다른 인증 방법이 있으면 재설정을 계속할 수 있습니다.
2. 표시된 전화번호 끝자리 등 본인이 볼 수 있는 비민감 정보만 확인합니다.
   - 예상 결과: 등록 연락처가 현재 사용하는 연락처와 다른지 판단할 수 있습니다.
3. 오류가 반복되거나 연락처가 다르면 더 시도하지 말고 오류 문구와 발생 시각을 기록해 Hops에 문의합니다.
   - 예상 결과: 계정 권한 담당자가 등록 연락처와 계정 상태를 검토합니다.

## 중단 및 이관 조건

- 다른 인증 방법이 없음
- 표시된 연락처가 현재 연락처와 다름
- 요청 처리 오류가 반복됨

## 문의에 준비할 정보

- 발생 시각
- 안전한 오류 문구
- 다른 인증 방법 표시 여부
- 등록 연락처가 현재 정보와 일치하는지 여부

## 하지 말아야 할 일

- 전체 전화번호·비밀번호·인증 코드를 문의에 입력하지 않기
- 오류가 반복될 때 재설정 요청을 계속 보내지 않기
- 관리자 화면이나 계정 설정을 임의로 변경하지 않기
