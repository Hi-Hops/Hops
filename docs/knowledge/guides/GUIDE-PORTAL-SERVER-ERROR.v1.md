# 사내 포털에서 서버 오류가 표시될 때

## 적용 상황

- 사내 포털 화면에 서버 오류나 500 오류가 표시됨
- 포털의 목록 또는 특정 상세 화면을 열 때 오류가 발생함

## 사용자 표현

- 포털 목록을 누르면 오류가 나요.
- 특정 항목의 상세 화면만 열리지 않아요.
- 포털에 500 오류가 떠요.

## 안전한 확인 순서

1. 오류 화면에 요청 추적 번호가 표시되면 복사하거나 화면을 캡처합니다.
   - 예상 결과: 담당자가 해당 요청의 서버 기록을 정확히 찾을 수 있습니다.
2. 오류가 난 메뉴·기능과 발생 시각을 기록합니다. 비밀번호·토큰·개인정보는 첨부하지 않습니다.
   - 예상 결과: 안전한 장애 범위 정보가 준비됩니다.
3. 같은 동작을 한 번만 다시 시도합니다.
   - 예상 결과: 일시 오류였다면 정상 화면이 열립니다.
4. 다시 실패하면 요청 추적 번호와 발생 시각을 포함해 Hops에 문의합니다.
   - 예상 결과: 담당 부서가 근거를 가지고 점검할 수 있습니다.

## 중단 및 이관 조건

- 한 번 다시 시도해도 같은 오류가 발생함
- 여러 메뉴 또는 여러 사용자가 동시에 오류를 겪음
- 업무 제출·저장처럼 중복 실행 위험이 있는 동작에서 오류가 발생함

## 문의에 준비할 정보

- 요청 추적 번호
- 발생 시각
- 오류가 난 메뉴 또는 기능
- 전체 포털인지 특정 화면·항목인지
- 안전한 오류 화면 캡처

## 하지 말아야 할 일

- 같은 저장 동작을 계속 반복하지 않기
- 비밀번호·인증 토큰·개인정보를 문의에 붙이지 않기
- 개발자 도구나 내부 서버 주소를 임의로 변경하지 않기
