# 회사 계정 비밀번호를 잊었을 때

## 적용 상황

- 회사 계정 비밀번호를 잊어 로그인할 수 없음
- 회사에서 제공한 셀프서비스 비밀번호 재설정 화면을 이용하려 함

## 사용자 표현

- 회사 계정 비밀번호를 잊었어요.
- 비밀번호가 기억나지 않아 로그인할 수 없어요.

## 안전한 확인 순서

1. 회사에서 안내한 공식 비밀번호 재설정 화면인지 주소를 확인합니다.
   - 예상 결과: 가짜 로그인 화면이 아닌 승인된 경로에서 재설정을 시작합니다.
2. 등록된 대체 인증 수단으로 본인 확인을 시도합니다. 비밀번호와 인증 코드는 Hops 대화에 입력하지 않습니다.
   - 예상 결과: 본인 확인이 가능하면 새 비밀번호를 설정할 수 있습니다.
3. 본인 확인 수단을 사용할 수 없거나 재설정이 실패하면 오류 문구와 발생 시각만 기록해 Hops에 문의합니다.
   - 예상 결과: 계정 권한 담당자가 신원 확인과 재설정 필요 여부를 검토합니다.

## 중단 및 이관 조건

- 등록된 본인 확인 수단을 사용할 수 없음
- 공식 재설정 화면에서 오류가 반복됨
- 계정 잠금 또는 차단 문구가 표시됨

## 문의에 준비할 정보

- 발생 시각
- 안전한 오류 문구
- 셀프서비스 재설정 화면 진입 가능 여부
- 사용 가능한 대체 인증 수단 유무

## 하지 말아야 할 일

- 현재 또는 새 비밀번호를 Hops에 입력하지 않기
- 인증 코드를 다른 사람에게 전달하지 않기
- 검색 결과의 임의 비밀번호 재설정 사이트를 이용하지 않기
