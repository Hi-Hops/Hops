# 공유 드라이브에 빨간 X가 보이거나 열리지 않을 때

## 적용 상황

- 탐색기의 회사 공유 드라이브에 빨간 X가 표시됨
- 오류 53·0x80004005·0x80070035와 함께 공유 경로가 열리지 않음

## 사용자 표현

- Z 드라이브에 빨간 X가 보여요.
- 공유 드라이브 경로를 찾을 수 없다고 나와요.
- 공유 폴더가 갑자기 열리지 않아요.

## 안전한 확인 순서

1. 사내망 또는 승인된 회사 VPN에 연결되어 있는지 확인합니다.
   - 예상 결과: 회사 파일 서버에 접근할 기본 네트워크 조건을 확인합니다.
2. 회사에서 제공한 서버 이름과 공유 경로가 맞는지 확인합니다. 전체 경로에 민감한 정보가 있으면 문의에 그대로 붙이지 않습니다.
   - 예상 결과: 오타나 오래된 경로인지 구분할 수 있습니다.
3. 탐색기에서 공유 드라이브를 한 번만 다시 엽니다.
   - 예상 결과: 일시적인 연결 끊김이면 드라이브가 다시 열립니다.
4. 같은 오류가 반복되면 오류 코드와 발생 시각을 기록해 Hops에 문의합니다.
   - 예상 결과: 네트워크 또는 시스템 담당자가 경로 연결 상태를 확인합니다.

## 중단 및 이관 조건

- 오류 53·0x80004005·0x80070035가 반복됨
- 같은 서버의 여러 공유 폴더가 함께 열리지 않음
- 여러 사용자가 같은 드라이브에 접근할 수 없음

## 문의에 준비할 정보

- 드라이브 문자
- 마스킹한 서버·공유 이름
- 오류 코드와 안전한 문구
- 발생 시각
- 사내망·VPN 연결 여부
- 다른 회사 공유 경로의 접근 여부

## 하지 말아야 할 일

- SMB1·NetBIOS·고정 IP를 임의로 활성화하지 않기
- 방화벽·서비스·레지스트리를 변경하지 않기
- 보안 프로그램을 제거하지 않기
- 파일 경로에 포함된 개인정보를 그대로 공유하지 않기
