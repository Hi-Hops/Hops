# 로그인이 반복 요청될 때

상태: 합성 가상 기업 안내 초안 · 내용·권한·출처 검수 전 · 검색 적재 금지. 대상: 공통 로그인. 실제 기업 화면·운영 기록을 나타내지 않는다.

## 상황

로그인 이후 다시 로그인 화면으로 이동하는 상황.

## 확인할 내용

이용한 시스템과 반복되는 화면·시점을 확인한다. 인증 정보를 문의에 입력하지 않는다.

## 담당자에게 전달할 정보

보고 시스템, 반복 단계, 발생 시점과 공개 가능한 오류 내용. 비밀번호·토큰·인증 코드는 입력하지 않는다. 안내로 해결되지 않으면 확인된 내용과 미확인 내용을 담당자에게 전달한다. 실제 해결은 문의자가 확인한다.

## 단계별 안내 후보

1. **대상 확인:** 어느 업무 화면에서 어떤 단계로 되돌아가는지 확인한다.
   - 대상 시스템과 기능을 문의자가 확인하지 못하면 모르는 상태로 보존하고 시스템 선택을 요청한다.
2. **맥락 확인:** 공개 가능한 오류 메시지와 이미 시도한 내용을 기록한다. 비밀번호·인증 코드·토큰은 요청하지 않는다.
   - 이미 문의자가 설명한 항목은 반복하지 않고 필요한 정보만 질문한다.
3. **안내·확인:** 확인된 정보와 허용된 직원 가이드가 일치하면 안내한 뒤 실제로 해결됐는지 문의자에게 확인한다.
   - 실제 안내가 없거나 적용 조건을 확인할 수 없다면 설명을 지어내지 않는다.

## 담당자 연결 조건

- 공통 로그인 책임을 뒷받침할 근거가 부족하면 보고 시스템 주담당자가 최초 조사한다.
- 담당자에게 전달할 정보: 보고한 시스템·로그인 반복이 시작되는 단계와 시점. 확인하지 못한 정보는 미확인으로 표시한다.
- 검색 결과가 없는 것과 검색 시스템이 실패한 것을 구분한다. 접수·안내만으로 해결이나 실제 시스템 변경 성공을 확정하지 않는다.

## 적용 범위와 검수

이 문서는 공통 로그인 관련 합성 초안이다. 실제 화면·기능 경계·출처·직원 공개 범위와 버전 검수가 필요하며 검수 전 검색에 적재하지 않는다.
