# 기능 추가·개선 요청 방법

상태: 합성 가상 기업 안내 초안 · 내용·권한·출처 검수 전 · 검색 적재 금지. 대상: 공통. 실제 기업 화면·운영 기록을 나타내지 않는다.

## 상황

현재 작업이 불편해 기능 변경을 요청하는 상황.

## 확인할 내용

현재 방식, 불편한 점과 원하는 변경을 설명한다. 접수는 구현 승인이나 구현 완료가 아니다.

## 담당자에게 전달할 정보

대상 시스템·기능, 현재 방식, 문제점과 원하는 변경. 비밀번호·토큰·인증 코드는 입력하지 않는다. 안내로 해결되지 않으면 확인된 내용과 미확인 내용을 담당자에게 전달한다. 실제 해결은 문의자가 확인한다.

## 단계별 안내 후보

1. **대상 확인:** 신규 기능인지 기존 기능의 개선인지와 현재 업무 방식을 확인한다.
   - 대상 시스템과 기능을 문의자가 확인하지 못하면 모르는 상태로 보존하고 시스템 선택을 요청한다.
2. **맥락 확인:** 변경 목적과 문의자가 확인한 내용을 표준 요청으로 정리한다.
   - 이미 문의자가 설명한 항목은 반복하지 않고 필요한 정보만 질문한다.
3. **안내·확인:** 확인된 정보와 허용된 직원 가이드가 일치하면 안내한 뒤 실제로 해결됐는지 문의자에게 확인한다.
   - 실제 안내가 없거나 적용 조건을 확인할 수 없다면 설명을 지어내지 않는다.

## 담당자 연결 조건

- AI가 제안한 수용 조건은 문의자·담당자 확인 전 확정 요구사항으로 표현하지 않는다.
- 담당자에게 전달할 정보: 대상 시스템·기능, 현재 방식·불편한 점·원하는 변화. 확인하지 못한 정보는 미확인으로 표시한다.
- 검색 결과가 없는 것과 검색 시스템이 실패한 것을 구분한다. 접수·안내만으로 해결이나 실제 시스템 변경 성공을 확정하지 않는다.

## 적용 범위와 검수

이 문서는 공통 관련 합성 초안이다. 실제 화면·기능 경계·출처·직원 공개 범위와 버전 검수가 필요하며 검수 전 검색에 적재하지 않는다.
