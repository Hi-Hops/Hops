# 결재 문서 작성 방법

상태: 합성 가상 기업 안내 초안 · 내용·권한·출처 검수 전 · 검색 적재 금지. 대상: 전자결재. 실제 기업 화면·운영 기록을 나타내지 않는다.

## 상황

문서 작성 메뉴와 양식을 찾으려는 상황.

## 확인할 내용

결재 시스템의 문서 작성 기능을 확인한다. 사용할 양식과 필요한 항목은 실제 화면 또는 승인된 가이드에서 확인한다.

## 담당자에게 전달할 정보

사용하려는 문서 종류와 현재 보고 있는 화면. 비밀번호·토큰·인증 코드는 입력하지 않는다. 안내로 해결되지 않으면 확인된 내용과 미확인 내용을 담당자에게 전달한다. 실제 해결은 문의자가 확인한다.

## 단계별 안내 후보

1. **대상 확인:** 결재 문서의 작성 기능이 어떤 위치에 있는지 가이드에서 확인한다.
   - 대상 시스템과 기능을 문의자가 확인하지 못하면 모르는 상태로 보존하고 시스템 선택을 요청한다.
2. **맥락 확인:** 사용하려는 문서 유형과 현재 위치를 확인한 뒤 승인된 안내 범위에서 다음 단계를 설명한다.
   - 이미 문의자가 설명한 항목은 반복하지 않고 필요한 정보만 질문한다.
3. **안내·확인:** 확인된 정보와 허용된 직원 가이드가 일치하면 안내한 뒤 실제로 해결됐는지 문의자에게 확인한다.
   - 실제 안내가 없거나 적용 조건을 확인할 수 없다면 설명을 지어내지 않는다.

## 담당자 연결 조건

- 안내한 기능을 찾지 못하거나 필요한 양식·권한이 확인되지 않으면 담당자에게 전달한다.
- 담당자에게 전달할 정보: 문서 종류와 결재 화면의 현재 단계. 확인하지 못한 정보는 미확인으로 표시한다.
- 검색 결과가 없는 것과 검색 시스템이 실패한 것을 구분한다. 접수·안내만으로 해결이나 실제 시스템 변경 성공을 확정하지 않는다.

## 적용 범위와 검수

이 문서는 전자결재 관련 합성 초안이다. 실제 화면·기능 경계·출처·직원 공개 범위와 버전 검수가 필요하며 검수 전 검색에 적재하지 않는다.
