# Hops IT 문의 처리와 해결 확인 절차

## 적용 상황

- Hops 문의가 어떻게 분석·안내·이관되는지 알고 싶음
- 안내 또는 담당자 처리 후 해결 확인 절차를 알고 싶음

## 사용자 표현

- 문의하면 어떤 순서로 처리되나요?
- 답변으로 해결되지 않으면 어떻게 되나요?
- 티켓은 언제 완료되나요?

## 안전한 확인 순서

1. Hops의 추가 질문에는 확인 가능한 사실만 답합니다.
   - 예상 결과: 서비스·증상·오류·영향 범위가 정리됩니다.
2. 근거가 있는 안전한 안내를 받은 경우 순서대로 수행하고 해결 여부를 알려 줍니다.
   - 예상 결과: 해결되면 티켓 없이 문의를 마칠 수 있고, 미해결이면 같은 문맥으로 진단을 이어갑니다.
3. 담당자 조치가 필요하면 생성된 티켓과 배정 부서를 확인합니다.
   - 예상 결과: 담당 부서가 대화 맥락과 근거를 이어받아 처리합니다.
4. 담당자 처리 완료 후 실제 해결 여부를 확인해 응답합니다.
   - 예상 결과: 해결된 티켓만 완료되고, 미해결이면 처리가 이어집니다.

## 중단 및 이관 조건

- 가이드 수행 후에도 해결되지 않음
- 근거가 부족하거나 설정 변경·재시작·권한 변경이 필요함
- 안내와 현재 증상이 일치하지 않음
- 서로 다른 문제가 한 문의에 함께 있음

## 문의에 준비할 정보

- 추가 질문에 대한 확인 결과
- 수행한 안전 조치와 결과
- 연결된 티켓 번호
- 담당자 처리 후 실제 해결 여부

## 하지 말아야 할 일

- Agent 답변만으로 해결 또는 업무 변경이 확정됐다고 가정하지 않기
- 설정 변경·재시작·권한 변경을 Agent에게 요구하지 않기
- 미해결 상태에서 해결됐다고 응답하지 않기
- 별개 문제를 기존 장애의 해결 결과로 섞지 않기
