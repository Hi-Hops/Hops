# 사내 포털 저장이 끝나지 않거나 실패할 때

## 적용 상황

- 포털의 저장·제출·상태 변경 작업이 오래 대기함
- 동시에 저장할 때 한 요청이 실패함

## 사용자 표현

- 포털 저장이나 제출이 멈췄어요.
- 저장 버튼을 눌렀는데 반영됐는지 모르겠어요.
- 다시 저장하면 오류가 나요.

## 안전한 확인 순서

1. 저장 버튼을 다시 누르기 전에 현재 화면에서 반영 여부를 확인합니다.
   - 예상 결과: 이미 처리된 작업을 중복 실행하는 위험을 줄입니다.
2. 요청 추적 번호와 발생 시각, 수행한 저장 동작을 기록합니다.
   - 예상 결과: 담당자가 대기 또는 실패 요청을 구분할 수 있습니다.
3. 반영 여부를 알 수 없거나 같은 문제가 반복되면 추가 저장을 중단하고 Hops에 문의합니다.
   - 예상 결과: 중복 데이터 변경 없이 담당 부서가 상태를 확인합니다.

## 중단 및 이관 조건

- 저장 결과를 확인할 수 없음
- 같은 동작이 두 번 반영될 가능성이 있음
- 여러 사용자가 같은 저장 지연을 겪음

## 문의에 준비할 정보

- 요청 추적 번호
- 발생 시각
- 저장하려던 업무 종류
- 현재 화면의 반영 여부
- 오류 문구

## 하지 말아야 할 일

- 결과를 모르는 상태에서 저장 버튼을 반복해서 누르지 않기
- 개인정보가 들어간 입력값 전체를 문의에 붙이지 않기
- DB 세션이나 브라우저 저장소를 직접 조작하지 않기
