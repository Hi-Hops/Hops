# 휴대폰 분실·번호 변경·MFA 코드 미수신 시

## 적용 상황

- 휴대폰 분실 또는 번호 변경으로 기존 MFA를 사용할 수 없음
- 문자 또는 음성 인증 코드가 도착하지 않음

## 사용자 표현

- 휴대폰을 잃어버려서 인증할 수 없어요.
- 번호를 바꾼 뒤 인증 문자가 오지 않아요.
- MFA 코드가 오지 않아요.

## 안전한 확인 순서

1. 로그인 화면의 다른 인증 옵션에서 본인이 이미 등록한 다른 수단을 사용할 수 있는지 확인합니다.
   - 예상 결과: 다른 승인된 수단으로 로그인할 수 있는지 확인합니다.
2. 본인 화면에 표시된 전화번호 끝자리가 현재 번호와 일치하는지만 확인합니다.
   - 예상 결과: 코드 미수신이 등록 연락처 불일치인지 구분할 단서가 생깁니다.
3. 다른 수단이 없거나 휴대폰을 분실했다면 추가 시도를 중단하고 Hops에 문의합니다.
   - 예상 결과: 계정 권한 담당자가 신원 확인 후 복구 절차를 진행합니다.

## 중단 및 이관 조건

- 휴대폰 분실로 기존 수단에 접근할 수 없음
- 다른 인증 옵션이 없음
- 표시된 전화번호가 현재 번호와 다름
- 계정 차단 문구가 표시됨

## 문의에 준비할 정보

- 증상 유형: 분실·번호 변경·코드 미수신
- 발생 시각
- 다른 인증 옵션 유무
- 표시된 번호가 현재 번호와 일치하는지 여부

## 하지 말아야 할 일

- 인증 코드·비밀번호·복구 비밀을 입력하지 않기
- 분실한 장치를 되찾기 전까지 안전하다고 가정하지 않기
- 관리자 초기화나 인증 수단 삭제를 직접 시도하지 않기
