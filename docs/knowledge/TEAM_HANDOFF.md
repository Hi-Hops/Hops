# Knowledge 데이터 전환 안내

기준: [PRD 1.44](../PRD.md) · 팀 합의 제품 방향. 신규 정책 5건은 [v1 데이터 초안](../../datasets/knowledge/v1/README.md)에 작성됐으며 AI 작성·담당자 검수 전·`PENDING` 상태다. 기존 v0 자료는 코드와 생성기 호환을 위해 남아 있으나 새 시스템·정책의 검색 정본이 아니다.

## 읽는 순서

1. [가상 기업과 세 시스템](VIRTUAL_COMPANY.md), [지식·평가 데이터 범위](DATASETS.md).
2. [지식 수명주기](KNOWLEDGE_LIFECYCLE.md), [새 정책](policies/POLICY-PRD-1.44.md), [Knowledge 분석 책임](KNOWLEDGE_DIAGNOSIS_CONTRACT.md).
3. [시나리오 후보](INCIDENT_SCENARIOS.md), [기존 자료 전환 목록](DATA_MIGRATION_REVIEW.md), [검수 체크리스트](REVIEW_CHECKLIST.md).
4. [목표 공통 계약](../../specs/contracts/TARGET_CONTRACT.md)과 구현 중인 서비스의 현재 상태.

## 다음 작업

- 시스템 ID·기능 경계·가상 인물과 주담당 관계를 정하고 합성 사례·문의·관계·평가 데이터를 구축한다.
- 기존 가이드·런북·정책과 기계 판독 원본을 자료별 검토하고 새 기획의 출처·권한·버전에 맞게 수정한다.
- 승인 사례의 문의자 확인·담당자 승인·동일 버전 양쪽 반영 및 검색 공개를 구현하고 결과를 검증한다.
- 데이터 담당자 검수·팀 리뷰, schema·청크·해시·manifest와 검색 적재는 각각 별도 단계로 기록한다.

이전 담당자 검수 상태나 v0 생성 성공은 v1 자료 승인·실제 모델 품질·E2E 성공이 아니다.

## 작업별 인계 내용

| 작업 축 | 다른 담당자에게 전달할 내용 | 완료로 오인하지 않을 사항 |
|---|---|---|
| 가상 기업·소유권 | 세 시스템의 기능 경계, 가상 사용자·주담당 관계, 시스템 간 의존과 근거 | 후보 시스템 목록이 실제 서버의 담당자 DB 구현을 뜻하지 않는다. |
| 직원 가이드·런북 | 대상 시스템·상황·출처·적용 조건, 직원/담당자 공개 범위, 초안·검수 상태 | Markdown 초안이나 v0 데이터 확인만으로 새 JSON·검색 적재가 완료되지 않는다. |
| 정책·사례 | 문의자 확인·담당자 승인, 출처와 적용 버전, 두 저장소별 승인 버전 반영 결과 | 팀 공통 데이터 리뷰와 제품 내 사례 승인은 별개다. |
| 검색·관계 | 승인 문서/사례와 접근 범위, 관계 후보·출처, Vector/Neo4j 검증 방법 | 관계 존재가 현재 문의의 확정 원인·실제 시스템 관측을 뜻하지 않는다. |
| 평가·시연 | 가상 문의와 응답 대본, 기대 행동, 평가 사건·검색 자료 분리, 고정 버전 | 시나리오 후보가 확정 평가셋이나 실측 성과를 뜻하지 않는다. |
| Spring·Frontend | 현재 업무 계약·대상 권한과 미결정 API/상태·오류 | AI 제안·모델 성공이나 화면만으로 저장·배정·공개를 확정하지 않는다. |

공유 PR에는 작성한 데이터의 출처·사용 조건·검수자·검증한 명령·결과와 미실행 사유를 적는다. 팀 공통 데이터의 승인 전 개인 실험 데이터나 설정을 다른 담당자의 필수 입력으로 강제하지 않는다. 가상 시나리오에는 실제 개인정보나 비밀값을 넣지 않는다.

## 데이터 전환의 권장 순서

1. 새 세 시스템과 기능·소유권의 가상 데이터를 설계하고, 기존 v0의 재사용 후보와 기술 사실·권한 범위를 대조한다.
2. 직원 가이드·런북·정책과 사례에 문서 버전·적용 조건·출처·확인 상태를 작성한다. 팀 리뷰와 제품 내 사례 승인을 각각 추적한다.
3. 동일 데이터의 기계 판독 구조·문서·관계·시나리오 참조를 맞추고 생성된 청크·해시·manifest를 검증한다.
4. 승인 사례의 동일 버전 Vector·Neo4j 반영과 권한별 공개를 실제 서비스에서 검증한다. 한쪽 실패나 미확인은 비공개로 유지한다.
5. 평가 사건을 별도로 고정하고 동일 지식·권한·모델 조건의 검색 비교와 다음 문의 재사용을 검증한다.

각 단계는 선행 자료에 따라 작은 리뷰 단위로 수행할 수 있다. 현재 일부 v1 문서와 정책 JSON은 검수 전 초안이며 새 카탈로그·사례·관계·평가 데이터와 색인 구현은 아직 준비되지 않았다.
