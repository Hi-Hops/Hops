# F003 문의 시작·채팅·추가 질문

상태: PRD 1.44 목표 명세 · 팀 기획 합의 / hops-system-1 구체 계약안 추가·팀 리뷰/구현/검증 별도.

## 1. 목표와 범위

문의자가 자연어로 요청을 시작하고 Inquiry와의 대화로 처리 가능한 정보를 구체화한다.

근거: [PRD](../../docs/PRD.md), [API](../../docs/API.md), [데이터](../../docs/DATA.md), [목표 공통 계약](../contracts/TARGET_CONTRACT.md).

## 2. 인수 조건

- **F003-TARGET-01:** 시스템을 선택하지 않고도 문의할 수 있으며 보고 시스템이 불명확하면 문의자에게 확인한다.
- **F003-TARGET-02:** 문제마다 최대 5회 질문 묶음을 보내고 확인된 정보는 반복하지 않는다. 질문 하나에 여러 항목이 있더라도 보낸 묶음 한 회로 센다.
- **F003-TARGET-03:** 한도 후 시스템이 확인됐다면 누락 항목을 명시해 담당자에게 전달한다.
- **F003-TARGET-04:** 시스템을 확인하지 못하면 지원 시스템 선택을 요청하고 확인 대기를 보존한다. 화면을 닫아도 해당 상태가 남는다.
- **F003-TARGET-05:** 범위 밖은 범위를 안내하고 티켓을 만들지 않는다. CS 검토 큐로 임의 배정하지 않는다.
- **F003-TARGET-06:** 승인된 직원용 가이드로 안내한 뒤 문의자가 해결을 확인하면 티켓 없이 종료할 수 있다. 검색 결과 없음과 검색 오류를 구분한다.
- **F003-TARGET-07:** 입력·저장 결과를 보존하고 서버 저장 확인 전 접수 성공을 표시하지 않는다.

## 화면과 사용자 흐름

### 화면

- 메인 문의 입력(`/`, 현재 프론트 경로), 본인 문의 채팅(`/inquiries/:inquiryId/chat`, 현재 경로).
- 채팅은 사용자/AI 메시지·공개 가능한 진행·질문·문제별 결과와 필요 시 시스템 선택을 표시한다. 티켓 접수 결과 모달은 F005에 연결한다.

### 흐름

1. 사용자가 시스템 선택 없이 자연어로 문의한다. Spring 저장 결과를 확인하고 Inquiry 실행을 진행한다.
2. 보고 시스템이나 필요한 정보가 부족하면 문제별 질문을 하고, 시스템 확인이 끝내 안 되면 지원 시스템 선택 대기로 남긴다.
3. 가이드로 해결되면 확인 후 무티켓 종료한다. 담당자 처리가 필요하면 표준 요청과 F005 티켓 결과로 연결한다.

## 상세 인수 조건과 예외

- **F003-DETAIL-01 첫 저장과 입력:** 현재 프론트 입력 프로필은 1~4,000 Unicode 코드 포인트, 공백만 있는 내용과 범위 초과 거부다. 원문은 잘라서 저장하지 않는다. 새 공통 계약 전환 시 이 기준의 유지 여부를 확인한다.
- **F003-DETAIL-02 결과 미확인:** 저장 요청 후 응답이 유실되면 내용을 보존하고 미확인으로 표시한다. 같은 업무 요청의 결과 확인 전 새 문의를 중복 생성하지 않는다.
- **F003-DETAIL-03 대화 조회:** 기존 프로필은 최신 30개를 오름차순으로 표시하고 이전 커서로 과거 30개를 추가한다. 과거 조회 실패는 이미 보이는 대화를 지우지 않으며 현재 스크롤 위치를 보존한다.
- **F003-DETAIL-04 질문 5회:** 문제별로 보낸 질문 묶음 수를 서버 값으로 관리한다. 5회 후 시스템이 확인됐다면 누락 항목을 표시해 담당자에게 넘긴다.
- **F003-DETAIL-05 시스템 미확인:** 5회 후에도 시스템이 확인되지 않으면 화면에서 지원 시스템을 선택하게 하고, 미선택·화면 종료 시 저장된 확인 대기를 유지한다.
- **F003-DETAIL-06 답변·범위:** 권한이 허용된 승인 가이드가 있으면 안내한다. 검색 없음과 오류를 구분하고 범위 밖은 안내만 제공한다.
- **F003-DETAIL-07 실행 실패:** 모델 오류·시간 초과·통신 오류를 문의 해결 실패나 범위 밖과 구분한다. 입력·이미 저장된 티켓을 유지하며 재분석은 아래 신규 RunRetryCommand 계약안을 따른다.
- **F003-DETAIL-08 최신 입력:** 버전 충돌·오래된 분석 결과는 F004에 따라 최신 저장 상태를 조회하고 사용자 입력을 보존한다.
- **F003-DETAIL-09 배정 후 메시지:** 배정된 문제에 추가된 내용은 해당 티켓 보완 정보로 저장하며 자동 새 티켓이나 재배정을 하지 않는다.

## 계약·화면 상태

신규 `hops-system-1` 팀 리뷰용 구체 계약안이다. 필드·enum은 [DATA_TYPES](../contracts/DATA_TYPES.md#신규-계약-hops-system-1), REST·오류·SSE·멱등성은 [WIRE_CONTRACT 12절](../contracts/WIRE_CONTRACT.md#12-신규-계약-hops-system-1), 업무 전이는 [TARGET_CONTRACT](../contracts/TARGET_CONTRACT.md)가 정본이다. 아래 내용은 구현·팀 승인·통합 완료 표시가 아니다.

| 조작 | 계약·검증 |
|---|---|
| 시작·전송 | InquiryCreateCommand/MessageSendCommand → CommandReceipt. 저장 확인 후 문의로 이동하며 분석 성공까지 기다리지 않음 |
| 대화 조회 | 소유자 MessagePage 최신 30개·이전 배타적 커서. 이미 보이는 대화·스크롤 유지 |
| 질문·시스템 선택 | 서버 questionCount=0~5. SystemConfirmCommand는 현재 문의 버전 검사·시스템 대기 저장 후 재진입 복원 |
| 가이드 | 승인 EMPLOYEE 근거 표시·GUIDE ResolutionRequest에 해결/미해결 응답. 미해결은 담당자 연결 검토 |
| 실행 재시도 | 현재 FAILED/TIMED_OUT Run에 RunRetryCommand. 티켓 생성 재시도와 별도 |
| 배정 후 보완 | problemIds로 관련 티켓 연결. 대상 불명확은 선택 요청; 자동 새 티켓·재배정 없음 |

| 화면 상태 | 관찰 가능한 동작 |
|---|---|
| WAITING_USER | 해당 문제의 질문 묶음과 서버 횟수 표시 |
| WAITING_SYSTEM | 지원 시스템 선택·선택하지 않아도 대기 유지. 새 자유 질문으로 5회 우회 금지 |
| 가이드 확인 대기 | 근거와 해결/미해결 버튼·대상 문제 표시 |
| 검색 EMPTY / ERROR | 근거 없음과 검색 불가를 다른 안내로 표시 |
| 저장 UNKNOWN / 분석 실패 | 원본 입력·동일 요청 키 보존과 결과 확인 / 새 run 재분석을 구분 |

## hops-system-1 검증 시나리오

- **F003-CONTRACT-01:** 같은 questionBundleId의 저장/재전달은 한 번만 집계해 5회를 넘기지 않는다.
- **F003-CONTRACT-02:** 5회·시스템 미확인에서 닫고 다시 열어도 동일 WAITING_SYSTEM과 질문 수가 복원된다.
- **F003-CONTRACT-03:** 가이드로 해결한 문제는 티켓·Curator 없이 해결되고 미해결 안내는 담당자 연결로 이어진다.
- **F003-CONTRACT-04:** 새 문의 저장 후 응답 유실을 같은 키로 재확인하면 원 문의 하나만 표시한다.

문서/JSON 검사·Mock·실제 서버 저장/권한·실제 AI/검색·브라우저 E2E를 분리해 결과를 기록한다. 기존 테스트의 이전 AC 번호를 새 시나리오 통과로 간주하지 않는다.

## 범위·연관 기능

- 질문 한도 우회용 추가 질문 루프, 무응답의 자동 배정·CS 검토, 답변 제공만으로 해결 확정은 제외한다.

## 현재 구현과 남은 작업

현재 프론트에 채팅·Mock이 있으나 새 질문 정책, Knowledge 및 실제 서버 전체 흐름은 아직 검증되지 않았다.

기존 코드·테스트의 인수 조건 번호는 이전 기준이며 목표 조건과 구분한다. 목표 AC는 실제 구현·검증 완료를 뜻하지 않는다. 실제 구현 범위는 서비스 코드와 실행 안내에서 확인한다.

기능의 목표 인수 조건은 구현·통합 검증을 대신하지 않는다. hops-system-1 계약안의 담당자 리뷰·승인 후 코드·테스트를 전환한다. 현재 구현을 문서만으로 완료 처리하지 않는다.
