# 기능·이슈 연결 전환

기준: [PRD 1.44](../docs/PRD.md), [기능 목록](README.md). 기존 이슈는 부서 배정·단일 에이전트 MVP 범위를 기준으로 작성됐을 수 있다. 새 기획에 맞는 이슈 내용·의존 관계·담당자·완료 상태는 실제 GitHub 상태를 확인하고 별도로 검토한다. 문서 수정은 이슈의 생성·수정·종료나 개발 완료를 뜻하지 않는다.

## 작업 단위

1. 시스템·담당자·표준 요청과 문의·문제·티켓 데이터·API 전환.
2. Inquiry·Knowledge·Ticket·Curator 및 모델 Supervisor의 실제 연결.
3. 기능별 화면: 시스템 확인, 문제별 티켓, 담당자 처리, 문의자 해결 확인.
4. 사례 초안·승인·두 검색 저장소 반영·공개·재실행.
5. 합성 데이터·그래프·평가·권한 및 통합/E2E 검증.

이 작업 단위는 새 이슈를 이미 만들었다는 의미가 아니다. 기존 이슈의 범위와 실제 상태는 GitHub에서 확인한다.
