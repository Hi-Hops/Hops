# 이슈 #30·#31 대응표

상태: MVP/후속 개발 범위 반영 · 갱신 2026-10-25 · 이슈 본문 변경 별도 · 작성: frontend
기준: 이슈 #30·#31 본문(2026-10-21 조회), 이 폴더의 프론트엔드 스펙 F001~F010

이 표는 프론트 화면의 완료 기준만 대응시킨다. 이슈 항목 중 서버 저장·중복 방지처럼 서버가 보장할 부분은 해당 담당의 검증으로 확인한다.

이슈 작업 목록의 각 항목이 어느 스펙의 어느 인수 조건(`Fnnn-ACnn`)으로 확인되는지 정리한다. 스펙 인수 조건이 모두 충족돼도, 미정 계약이 남아 있으면 이슈 항목을 완료로 보지 않는다(이슈 본문 "미정인 필드·경로·예산은 기본값으로 확정하지 않는다").

판정:
- **대응**: 인수 조건으로 확인할 수 있다. 남은 미정 계약은 "막는 질문"에 적는다.
- **후속 확정**: Q-ALL-7의 범위 결정에 따라 MVP에서 제외했다. 실제 GitHub 이슈 본문/완료 조건 조정은 별도다.
- **스펙 밖**: 화면 인수 조건이 아니라 구현 PR의 검증·제출물로 확인한다. 이유를 적는다.
